# ASP Invoice Studio

Browser-based invoice tools for ASP Tech Solution and ASP & Auditors.

## Pages

- `index.html` or `invoice.html`: create and raise invoices
- `invoices.html`: saved invoices, business/date filters, and Excel export
- `settings.html`: business, bank, UPI, and payment QR settings

## Data

Invoices and settings are stored in the browser's local storage. Each browser/device has its own data. The static site does not send invoice or bank details to GitHub.

## Logos

The `.jpg.b64` files contain public logo assets in text form. GitHub Pages loads them for the page logo images.
